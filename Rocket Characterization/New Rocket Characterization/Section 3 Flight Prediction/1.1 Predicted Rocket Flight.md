With a thrust, weight, and burn time, it is possible to calculate the flight path of the rocket using Matlab. This matlab code was developed for use in ENGR 495, where it was used to predict the flight path of a small model rocket using a D-class motor. The program uses the standard drag equation with the standard atmosphere data to calculate atmospheric conditions at different altitudes.

![[rocket_performance.svg]]

This estimated performance is extremely off for a few reasons. For one, it assumes constant thrust, which will not be the case. As the rocket goes higher in altitude, the expansion conditions at the nozzle exit will change from over expanded at launch, to ideally expanded at about 8000 feet, to under expanded. This will change the thrust profile as the rocket goes higher. Also, this code was developed from ENGR 495, which used a small rocket with a D-class motor. This rocket never got close to Mach 1, so assuming a constant coefficient of drag or $C_D$ was fine. This was determined from wind tunnel data, and the rocket ended up with an average $C_D$ of 0.3 ish (it changed with velocity and I ended up plotting a curve for the rocket).

However, for a rocket with a TWR of 12 burning for almost 5 seconds, this plot estimates the rocket will reach Mach 1.6. Since the $C_D$ changes drastically as you approach transonic speeds (Mach 0.8-1.2), this matlab code is not suitable for predicting the rocket flight path. We know that the rocket will absolutely reach transonic speeds, but it is not certain that the rocket will go supersonic. To predict this, a better method of predicting the rocket flight path is needed.
